# On LLM usage in this repository

LLM Agents (such as Claude, Codex, GLM, or otherwise) must _not_ contribute code to this repository. Code written primarily by agents, carrying the agents watermarks, must _not_ be merged. Code that is aiming to be merged in to the repo must be written by humans.

Usage of LLM agents is therefore limited. Debugging, prototyping, research, helping with Git operations, mechanical renames, running linters, or other activities which does not end with trying to contribute LLM written code is acceptable.
